# نارون | فروشگاه آنلاین لوازم‌التحریر

یک قالب فروشگاهی فارسی، راست‌چین، واکنش‌گرا و آماده انتشار به‌صورت سایت استاتیک. بدون نصب وابستگی یا فرایند build اجرا می‌شود.

## امکانات
- صفحه اصلی فروشگاهی با طراحی واکنش‌گرا و مناسب موبایل
- کاتالوگ نمونه ۱۲ محصولی با دسته‌بندی و جستجو
- مرتب‌سازی بر اساس قیمت و نام
- علاقه‌مندی‌ها
- سبد خرید با تغییر تعداد و حذف محصول
- ذخیره سبد و علاقه‌مندی‌ها در `localStorage`
- فرم سفارش آزمایشی با اعتبارسنجی پایه و شماره سفارش
- طراحی فارسی و RTL
- مناسب میزبانی استاتیک مثل GitHub Pages و Cloudflare Pages

## اجرای محلی
فایل `index.html` را در مرورگر باز کنید. برای توسعه بهتر می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## انتشار در GitHub Pages
1. فایل‌های داخل ZIP را در ریشه یک repository آپلود کنید؛ فایل `index.html` باید در ریشه باشد.
2. در GitHub وارد **Settings → Pages** شوید.
3. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/ (root)` را انتخاب و Save کنید.
5. پس از انتشار، آدرس سایت در همان صفحه نمایش داده می‌شود.

## انتشار در Cloudflare Pages
1. یک پروژه Pages بسازید و repository را به آن متصل کنید.
2. چون پروژه بدون build است، فریم‌ورک را **None** انتخاب کنید.
3. Build command را خالی بگذارید و Build output directory را `/` یا ریشه پروژه تنظیم کنید.
4. Deploy را بزنید.

## نکته مهم درباره فروش واقعی
این بسته یک **فرانت‌اند آماده و دمو** است؛ پرداخت واقعی، پنل مدیریت، مدیریت موجودی، ارسال پیامک، حساب کاربری و ثبت سفارش روی سرور در آن پیاده‌سازی نشده‌اند. سفارش آزمایشی و سبد خرید در مرورگر کاربر ذخیره می‌شوند و فروشنده آن‌ها را دریافت نمی‌کند. برای راه‌اندازی فروش واقعی باید بک‌اند امن، پایگاه داده، پنل مدیریت، قوانین ارسال/مرجوعی و درگاه پرداخت معتبر متصل شود. اطلاعات کارت بانکی را هرگز در این قالب فرانت‌اند دریافت نکنید.

## سفارشی‌سازی سریع
- محصولات نمونه، قیمت‌ها، دسته‌ها و توضیحات: آرایه `products` در `app.js`
- رنگ‌ها و استایل: متغیرهای ابتدای `styles.css`
- متن‌ها و ساختار صفحه: `index.html`

## ساختار
- `index.html` — صفحه و اجزای فروشگاه
- `styles.css` — طراحی و واکنش‌گرایی
- `app.js` — جستجو، فیلتر، علاقه‌مندی، سبد و سفارش آزمایشی
- `assets/favicon.svg` — آیکن سایت
